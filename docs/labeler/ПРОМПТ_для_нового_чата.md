## Что нужно
1. Открыть корневую папку архива, найти все сессии, показывать **по одной сессии как «карточке»**: три графика (Task, Friction,
   Pressure; если какого-то нет, пустая рамка «нет в сессии»; по кнопке можно показать Stroke). Для первой версии проще
   показывать `.bmp` (быстро, есть почти везде) с предзагрузкой следующей карточки; открытие `.data` через ChartView
   для масштабирования можно добавить позже.
2. Панель разметки: общая оценка (норма / есть дефект / не уверен / непригодно), галочки дефектов по группам, поле «комментарий».
   Список меток **не зашивать в код**: читать из редактируемого файла (JSON) с версией, ключами и русскими названиями; черновик
   лежит в docs/labeler/ЧЕРНОВИК.md (группы: посадка и отрыв, трение, обратная связь/привод/шток, позиционер, TSO, течь,
   особенности настройки). Я позже допишу описания и добавлю метки (TSO: направление ошибки «на закрытие / на открытие» и
   «встаёт ниже / выше задания»), метки хранить по ключу, чтобы их можно было переименовывать и объединять.
3. «Далее» / «Назад» / «Пропустить», горячие клавиши (N норма, цифры дефекты, стрелки), Ctrl+Z. Прогресс «137 / 766».
4. Хранение: отдельный файл labels.sqlite рядом с архивом, **не** основная база приложения. Запись на карточку: относительный путь
   сессии, хэш файлов, оценка, список меток, комментарий, версия списка меток, время на карточку, время ответа; не перезаписывать,
   а добавлять новую запись (история правок). Возможность продолжить с того места, где остановился.
5. Скрытый «результат приложения» (числа и заключение из report.xlsx): за кнопкой «показать», по умолчанию скрыто, чтобы не
   подстраиваться под него. Учти: из report.xlsx выбранное оператором заключение извлечь надёжно не получилось (в каждом файле
