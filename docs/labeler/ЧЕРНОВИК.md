# Разметчик графиков: черновик списка меток и карточки

Статус: **черновик для правки автором**, код ещё не писался. Приложение — отдельная цель рядом с `DataViewer`
(`Viewer/`), в основную сборку не входит. Метки хранятся в отдельном файле `labels.sqlite`, не в `mpiplatform.db`.

## Откуда взят список

- Названия каталогов с флешки «Графики для анализа ИИ» (30 клапанов): tso, tso + отрыв, tso высокое, отрыв подъёмный,
  трение и позик, диапазон, характеристика, реверс, искривление штока, привод Logix, норма.
- Варианты заключения из шаблона отчёта приложения (лист «Заключение»), то есть словарь, которым уже пользуется оператор.

## Список меток v0

**0. Общая оценка (обязательна, одна)**

- норма
- есть дефект (отметить ниже)
- не уверен
- непригодно (график пустой, испорчен, не тот тест)

**1. Посадка и отрыв**

- резкий отрыв плунжера от седла
- низкое значение зоны посадки плунжер/седло
- зона посадки плунжер/седло отсутствует
- высокое значение зоны посадки плунжер/седло

**2. Трение**

- высокое трение в диапазоне 0–100 % хода
- высокое трение в диапазоне 0–50 % хода
- высокое трение в диапазоне 50–100 % хода
- высокое трение в средней зоне хода
- высокое трение при выходе плунжера/диска из седла

**3. Обратная связь, привод, шток**

- деформация адаптации/элементов обратной связи
- люфты адаптации/обратной связи
- искривление штока

**4. Позиционер**

- сбиты крайние точки
- некорректное отрабатывание заданной характеристики
- позиционер неработоспособен

**5. TSO — Tight Shut-Off** (функция позиционера). Метка «tso» в названии каталога = **ошибка позиционирования,
связанная с этой настройкой**: в одном направлении клапан встаёт нормально, а в другом «перепрыгивает» и встаёт ниже или выше.
Отмечаются два независимых признака:

- в каком направлении ошибка: при ходе на закрытие / при ходе на открытие
- как клапан встаёт: ниже задания / выше задания
- TSO выражено сильно (метка «tso высокое» в названии каталога)

**6. Течь**

- видимая течь

**7. Особенности настройки или теста** (дефект это или нет — решает автор; помечается отдельно)

- реверс
- диапазон
- характеристика (ЭПП)
- привод Logix

Плюс поле «комментарий» (свободный текст).

## Макет карточки (одна сессия)

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 137 / 766        АО ННК Хабаровский НПЗ · FV-33044 · 22.04.2024   [заказчик/позиция/дата] │
├──────────────────────────────────────────────────────────────────────────┤
│  ЗАДАНИЕ              │  ТРЕНИЕ               │  ДАВЛЕНИЕ                 │
│  (график)             │  (график)             │  (график)                 │
│                       │                       │                           │
├──────────────────────────────────────────────────────────────────────────┤
│ Оценка: (•) норма  ( ) есть дефект  ( ) не уверен  ( ) непригодно         │
│ Дефекты:  [ ] отрыв  [ ] трение 0-50%  [ ] люфты  [ ] tso  ...  (по группам) │
│ Комментарий: ____________________________________________________________ │
├──────────────────────────────────────────────────────────────────────────┤
│ [Показать результат приложения ▸]   ← скрыто, пока не ответите            │
│            [← Назад]        [Пропустить]        [Далее →]                 │
└──────────────────────────────────────────────────────────────────────────┘
```

- Показывается то, что есть в сессии: давление есть в 700 из 766 сессий, трение в 657, задание в 572, ход (`Stroke`) в 82.
  Недостающий график — пустая рамка с подписью «нет в сессии».
- «Результат приложения» (числа из `report.xlsx` и старое заключение оператора) скрыт до ответа, чтобы не подстраиваться;
  после ответа открывается, расхождения пишутся в отдельное поле.
- Клавиши: `N` норма, `Д` есть дефект, `?` не уверен, цифры — дефекты, `→` далее, `←` назад, `Ctrl+Z` отмена.
- Порядок: первые 100 карточек в случайном порядке (честная частота дефектов), дальше по группам; около 10 % карточек
  возвращаются позже для проверки собственной согласованности.

## Что сохраняется на каждую карточку

путь сессии (относительный), хэш файлов, оценка, список меток, комментарий, версия списка меток (v0), время на карточку,
дата. История правок не затирается (новая запись вместо перезаписи).
