# Основной тест — формулы `[ОТ-n]`

Код: `Src/Domain/Tests/Main/` (`Params.h`, `Standard/Algorithm.cpp`, `Analyzer.cpp`,
`CrossingStatusUpdater.cpp`), `Src/Domain/Program.cpp` (график трения).
Объяснения с выводами — лекция 09 (v2), линейность — лекции 12–13.

**Контрольное испытание** для примеров: PV-2223, ЛУКОЙЛ-УНП, висбрекинг, 03.10.2024
(`рез/ЛУКОЙЛ-УНП/ВИСБРЕКИНГ/-/PV-2223/03_10_2024/`, оба хода из `Pressure_1.data`,
`Task_1.data`). Отмечено **«= отчёт»**, где число совпало с `report.xlsx` приложения.

**Где какой ход в коде.** `Analyzer::onSample()` пишет **прямой** ход в массивы
`...Second`, **обратный** — в `...First`. В `.data` и на графиках: прямой ход — в
«дубль»-слое серии (`duplicateChartSeries` на старте обратного хода), обратный — в
основном.

## [ОТ-1] Шаги задания

$$
\text{dac}_i = \frac{i'\,(\text{dac}_{\max} - \text{dac}_{\min})}{N} + \text{dac}_{\min},
\quad i' = \begin{cases} N - i, & \text{descending} \\ i, & \text{иначе} \end{cases},
\quad \text{dac}_i \ge \text{dac}_{\text{floor}}
$$

| значок | что |
|---|---|
| $N$ | `pointNumbers` — число шагов прохода |
| $i$ | номер шага: 0…N на прямом ходе, N…0 на обратном |
| descending | обратная шкала (ход растёт при уменьшении задания) |

Каждый шаг — `response` мс; время шагов считается от начала прохода
(`time += response`), задержки не накапливаются. Между ходами — `delay` мс.

**В коде:** `Params.h` → `sweepDac()`, `sweepStartDac()`, `sweepEndDac()`;
`Standard/Algorithm.cpp` → `Algorithm::run()`.
**Пример:** PV-2223 — задание 3 → 21 мА, 2932 замера на ход, шаг ≈ 0,005 мА.
**Статус:** официальная.

## [ОТ-2] Границы хода

$$
y_{\min} = \min_{\text{оба хода}} y_i, \qquad y_{\max} = \max_{\text{оба хода}} y_i, \qquad R = y_{\max} - y_{\min}
$$

То же для давления: $x_{\min}$, $x_{\max}$.

**В коде:** `Analyzer::computePressureLimits()`.
**Пример:** PV-2223: $y_{\min} = -0{,}36$, $y_{\max} = 53{,}76$, $R = 54{,}12$ мм.
**Статус:** официальная.
**Вопросы:** границы по сырым min/max — один выброс сдвигает окно [ОТ-3] (лекция 12, §10).

## [ОТ-3] Рабочее окно 10–90 % хода

$$
y_{\min} + 0{,}1R \;\le\; y_i \;\le\; y_{\max} - 0{,}1R, \qquad \text{ширина окна} = 0{,}8R
$$

**В коде:** `calculateRegression()`, `computeLinearityError()` (константа `kWorkWindowFrac = 0.10`
в `Analyzer.cpp`); `Linearity::minimaxLinearity()` для [ОТ-7] (`kWindowFrac = 0.10`).
Границы окна → `Result::workWindowLow/High` (`applyRegressions()`).
**На графике:** серые полосы «Вне расчёта» на графике давления ниже `workWindowLow` и выше
`workWindowHigh` (`buildMainTestZones()`), только на экране — в отчёт не идут. Подсказка на
чипе легенды оговаривает, что [ОТ-12]/[ОТ-13] берут прямые, продолженные до краёв хода.
**Пример:** PV-2223: окно 5,05…48,35 мм (43,30 мм); в нём 1823 точки прямого хода и
1726 обратного. LV-453 06.11.2026: окно 1,44…13,24 мм, вне окна 107 из 313 точек прямого
хода и 102 из 313 обратного; прямые по окну совпадают с сохранёнными в `Давление_1.data`.
**Статус:** официальная.

## [ОТ-4] Прямая МНК (регрессия хода)

$$
k = \frac{n\sum x_i y_i - \sum x_i \sum y_i}{n\sum x_i^2 - \left(\sum x_i\right)^2},
\qquad b = \frac{\sum y_i - k\sum x_i}{n}
$$

Суммы — по точкам окна [ОТ-3], **для каждого хода отдельно**. Регрессия недействительна,
если знаменатель ≈ 0 (давление в окне не менялось).

**В коде:** `Analyzer::calculateRegression()`; при ручной правке линий —
`regressionFromLine()` (та же формула по точкам перетащенной линии).
**Пример:** учебный — $(1;5), (5;25), (9;45)$ → $k = 5$, $b = 0$.
PV-2223: прямой $k = 89{,}07$, $b = -44{,}39$; обратный $k = 91{,}12$, $b = -42{,}43$.
**Статус:** официальная.

## [ОТ-5] Линии регрессии на графике

Прямая [ОТ-4], обрезанная рамкой $[x_{\min}, x_{\max}] \times [y_{\min}, y_{\max}]$:
берутся точки пересечения с краями рамки, лежащие внутри неё.

**В коде:** `Analyzer::buildRegressionLinePoints()`; на график — `Program::addRegression()`
(серия 1 — прямой ход, 2 — обратный).
**Статус:** официальная (отображение).
**Вопросы:** комментарий в `buildRegressionLinePoints()` говорит, что `regressionFromLine()`
берёт только `first()/last()` линии; на деле там МНК по всем точкам линии ([ОТ-4]) —
комментарий устарел.

## [ОТ-6] Линейность, интегральная (для сравнения)

$$
L_{\text{инт}} = \max_{\text{ход}}\ \frac{\max_i |y_i - (kx_i + b)|}{0{,}8R}\cdot 100\,\%
$$

**В коде:** `Analyzer::computeLinearityError()` → `Result::linearityErrorIntegral`.
**Пример:** PV-2223: прямой 1,871 мм / 43,30 = 4,32 %; обратный 3,29 %; итог 4,32 %
(превью приложения показывает 4,33 — расхождение в третьем знаке, не разбиралось).
**Статус:** официальная как поле `Result`, **в Pass|Fail не участвует**.

## [ОТ-7] Линейность, прямая минимакс (Pass|Fail)

$$
L = \max_{\text{ход}}\ \frac{\min_{k,b}\ \max_i |y_i - (kx_i + b)|}{0{,}8R}\cdot 100\,\%,
\qquad \text{linearity} = 100 - L
$$

Точки $i$ — рабочее окно [ОТ-3] одного хода. Прямая подбирается так, чтобы **наибольшее**
отклонение точки было наименьшим (минимакс, Чебышёв): наклон $k$ — тернарным поиском
вокруг наклона МНК (ширина полосы $\max(y-kx) - \min(y-kx)$ выпукла по $k$), $b$ —
середина полосы. Итог — худший из двух ходов.

**В коде:** `Analyzer::computeMinimaxLinearityError()` → `Linearity::minimaxLinearity()`
(`Src/Domain/Tests/Main/Linearity/LinearityMethods.cpp`, тот же расчёт, что [ЭЛ-2] в
карточке) → `Result::linearityError`, `Result::linearity`; итог —
`qMax(minimaxForward, minimaxBackward)` в `applyRegressions()`.
**Пример:** LV-453, сессия 864 (06.11.2026): прямой 3,96 %, обратный 4,73 % → **4,73 %**
(допуск в карточке 5 %).
**Статус:** официальная с 2026-11-12.
**История:** до 2026-11-12 официальной была дифференциальная линейность — наибольшее
отличие наклона МНК на участке из $\max(8, n/10)$ точек от общего наклона, % наклона, с
фильтром участков (дефект: порог 10 % равен размаху самого участка, на архиве отбрасывалась
около половины участков; лекция 13). На LV-453 она давала 43–49 % при допуске 5 %. Удалена
вместе с [ЭЛ-3]; у сессий, записанных до 2026-11-12, в базе осталось её число (а у ещё
более старых — [ОТ-6]).

## [ОТ-8] Разность давлений ходов на середине хода

$$
y_{\text{mean}} = \frac{y_{\max} + y_{\min}}{2}, \qquad
\Delta P = \left|\frac{y_{\text{mean}} - b_{\text{пр}}}{k_{\text{пр}}} - \frac{y_{\text{mean}} - b_{\text{обр}}}{k_{\text{обр}}}\right|
$$

**В коде:** `Analyzer::computePressureDiff()` → `Result::pressureDiff`.
**Пример:** PV-2223: $x_{\text{пр}} = 0{,}798$, $x_{\text{обр}} = 0{,}759$, **ΔP = 0,0395 бар**.
**Статус:** официальная.

## [ОТ-9] Сила трения

$$
F_{\text{тр}} = \Delta P \cdot \underbrace{5\cdot\frac{\pi D^2}{4}}_{\text{forceCoef}}
\qquad\left(= \tfrac12\,\Delta P \cdot 10\,\tfrac{\text{Н}}{\text{см}^2\cdot\text{бар}} \cdot A\right)
$$

| значок | что | единицы |
|---|---|---|
| $D$ | диаметр привода (`driveDiameter`) | см |
| ½ | перепад ходов — удвоенное трение | — |

**В коде:** `Analyzer::applyRegressions()` → `Result::frictionForce`.
**Пример:** PV-2223, $D = 11$ см: forceCoef = 475,2 Н/бар, **F = 18,77 Н = отчёт**.
**Статус:** официальная.

## [ОТ-10] Коэффициент трения

$$
\text{frictionPercent} = \frac{50\cdot\Delta P}{\left|x(y_{\min}) - x(y_{\max})\right|},
\qquad x(y) = \frac{y - b}{k}
$$

Знаменатель — диапазон давлений хода по прямой [ОТ-4]; 50 = 100/2 (та же половина петли).

**В коде:** `Analyzer::computeFrictionPercent()` → `Result::frictionPercent`.
**Пример:** PV-2223: **3,33 % = отчёт**.
**Статус:** официальная.
**Вопросы:** параметр функции называется `regressionForward`, но вызывается с
`regressionFirst` — регрессией **обратного** хода. По прямому ходу было бы 3,25 %.
Разночтение в имени; число отчёта соответствует коду.

## [ОТ-11] График трения по ходу

Ход делится на $S = \min(n_{\text{пр}}, n_{\text{обр}})/3$ секций по положению; в каждой —
$|\bar x_{\text{пр}} - \bar x_{\text{обр}}|$ (средние давления ходов), края по 5 % секций
пропускаются; на графике значение умножается на forceCoef [ОТ-9].

**В коде:** `Analyzer::buildFrictionChartPoints()`; × forceCoef — `Program::addFriction()`.
**Пример:** PV-2223: 13,5…26,9 Н, среднее 18,5 Н.
**Статус:** официальная (график).

## [ОТ-12] Полный диапазон давлений

$$
x_1 = x_{\text{пр}}(y_{\min}),\ x_2 = x_{\text{пр}}(y_{\max}),\ x_3 = x_{\text{обр}}(y_{\min}),\ x_4 = x_{\text{обр}}(y_{\max})
$$
$$
\text{low} = \min(x_1..x_4), \qquad \text{high} = \max(x_1..x_4)
$$

**В коде:** `Analyzer::computeRangeLimits()` → `lowLimitPressure`, `highLimitPressure`.
**Пример:** PV-2223: $x_{1..4}$ = 0,494; 1,102; 0,462; 1,056 → **0,462–1,102 бар = отчёт**
(0,46–1,10).
**Статус:** официальная.

## [ОТ-13] Диапазон пружины

$$
\text{springLow} = \tfrac12\big(\min(x_1,x_2) + \min(x_3,x_4)\big), \qquad
\text{springHigh} = \tfrac12\big(\max(x_1,x_2) + \max(x_3,x_4)\big)
$$

Среднее ходов — трение взаимно гасится.

**В коде:** `Analyzer::computeSpringLimits()` → `springLow`, `springHigh`.
**Пример:** PV-2223: **0,478–1,079 бар**.
**Статус:** официальная.
**Вопросы:** в отчёте 2024 г. в строке «заданный диапазон пружин» стоял полный диапазон
[ОТ-12]; в текущем `Report/Excel/Blocks/TechnicalResults.cpp` туда пишется [ОТ-13].

## [ОТ-14] Динамическая ошибка

Ход делится на $S = \min(n_{\text{пр}}, n_{\text{обр}})/3$ секций по положению (по точкам
графика задания: задание, мА — положение). В секции $s$ — средние задания ходов:

$$
d_s = \left|\bar I_{\text{пр},s} - \bar I_{\text{обр},s}\right|, \quad s \in [0{,}05S;\ 0{,}95S)
$$
$$
\text{dynamicErrorMean} = \frac{\overline{d_s}}{2}\ \text{мА}, \qquad
\text{dynamicErrorMax} = \max_s d_s\ \text{мА}, \qquad
\text{…Percent} = \frac{\text{мА}}{0{,}16}
$$

`dynamicErrorReal` = `dynamicErrorMeanPercent` (идёт в Pass|Fail).

**В коде:** `Analyzer::computeDynamicErrorMeanMax()`, `Analyzer::finish()`.
**Пример:** PV-2223: $S = 977$; $\overline{d} = 0{,}426$ мА → 0,213 мА = **1,33 % = отчёт**;
max 1,257 мА = 7,85 %.
**Статус:** официальная.
**Вопросы:** среднее делится на 2, максимум — нет. Намеренно ли — не выяснено.

## [ОТ-15] Проверки Pass|Fail

Общее правило: значение в допуске $[L, U]$ — «соответствует», иначе промах
$\text{miss} = v - L$ (ниже) или $v - U$ (выше).

| Параметр | Значение $v$ | Допуск $[L, U]$ |
|---|---|---|
| Коэффициент трения | [ОТ-10] | `frictionCoefLower` … `frictionCoefUpper` |
| Линейность | [ОТ-7] `linearityError` | 0 … `linearCharacteristic` |
| Динамическая ошибка | [ОТ-14] `dynamicErrorReal`, % | 0 … `dinamicErrorRecomend` |
| Ход клапана | ход, измеренный **при инициализации** (`DeviceInitializer::recordStrokeRange`) | паспорт ± `valveStroke` % |
| Пружина | [ОТ-13] низ и верх **отдельно** | `driveRangeLow` ± `springLower` %, `driveRangeHigh` ± `springUpper` % |

**В коде:** `CrossingStatusUpdater.cpp` → `missFrom()`, `updateCrossingStatus()`.
**Статус:** официальная.

## [ОТ-16] Ток страгивания

Для каждого хода исходное положение $y_0$ — медиана первых пяти замеров.
Порог $\delta = 0{,}002R$ берётся по полному измеренному ходу $R$ из [ОТ-2].
Начиная с шестого замера, берётся медиана положения по полному окну из пяти
замеров с центром в текущей точке. Два соседних центра должны дать отклонение
от $y_0$ строго больше порога по модулю. Ток страгивания — исходное задание
в мА в первом из этих двух центров. При отсутствии подходящей пары
результат отсутствует.

**В коде:** `Analyzer::finish()` → `breakawayForward`, `breakawayBackward`.

## Способы линейности для сравнения

Показываются в раскрывающейся карточке линейности блока Pass|Fail (штатная часть
приложения, без флага сборки). Способ [ЭЛ-2] по худшему ходу — это официальный [ОТ-7]
(выбран в карточке по умолчанию); остальные в Pass|Fail, отчёте и базе **не участвуют**. Код:
`Src/Domain/Tests/Main/Linearity/LinearityMethods.cpp`, карточка —
`Src/Gui/MainWindow/Linearity/`, подробно — лекция 13. Номера ЭЛ сохранены.

| № | Способ | Формула | Единицы |
|---|---|---|---|
| [ЭЛ-1] | МНК | = [ОТ-6] по выбранному ходу | % хода |
| [ЭЛ-2] | минимакс | $\frac{1}{0{,}8R}\min_{k,b}\max_i\lvert y_i - kx_i - b\rvert\cdot100\%$ | % хода |
| [ЭЛ-3] | *удалён 2026-11-12* | был прежний дифференциальный расчёт с фильтром (см. «История» в [ОТ-7]) | — |
| [ЭЛ-4] | участки по ходу, без фильтра | наибольшее $\lvert k_j - k\rvert / \lvert k\rvert\cdot100\%$, $k_j$ — МНК на участке 10 % хода, шаг 2,5 %, не короче 8 точек | % наклона |
| [ЭЛ-5] | CV | $\sqrt{\frac1m\sum_j d_j^2}$, $d_j = \frac{k_j - k}{\lvert k\rvert}\cdot100\%$ | % наклона |
| [ЭЛ-6] | средняя кривая | полосы 0,5 % хода по положению, медиана давления по каждому ходу, среднее; затем любой из ЭЛ-1…5 (IEC 61987 / IEC 61298-2) | — |

**Пример (PV-2223, прямой / обратный / средняя):** ЭЛ-1 4,33 / 3,29 / 1,74;
ЭЛ-2 3,60 / 2,79 / 1,55; (прежний ЭЛ-3 12,91 / 9,32 / 12,20); ЭЛ-4 15,08 / 14,12 / 13,39;
ЭЛ-5 8,14 / 5,98 / 6,28.

**Сверено с ISA-51.1-1979 (R1993)** (текст стандарта, 2026-11-06): «linearity, independent» —
определение на с. 38, порядок проверки — п. 5.5.5 на с. 63–64. Линейность — наибольшее
отклонение **средней кривой** (среднее прямого и обратного хода) от прямой, проведённой так,
чтобы это отклонение было минимальным, то есть ЭЛ-2 по ЭЛ-6. Два отличия от приложения:
1) ISA выражает её в % от **всего диапазона** выхода, у нас — от $0{,}8R$ (числа в 1,25 раза
больше); 2) ISA усредняет выход (положение) при одном входе (давлении), ЭЛ-6 — давление при
одном положении. «Гистерезис + мёртвая зона» по ISA (п. 5.5.4) — **полное** наибольшее
расхождение ходов, в % диапазона выхода (ср. [ОТ-14], где среднее делится на 2).
