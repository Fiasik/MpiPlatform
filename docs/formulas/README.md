# Справочник формул MpiPlatform

Здесь записано, **что именно считает приложение**: формула, обозначения и единицы,
где это в коде, контрольный пример и известные вопросы. Объяснения «почему так» с
выводами — в лекциях (`~/Documents/Work/Mpi/Лекции/`), здесь — короткая справка.

## Правила

1. **Номер формулы постоянный**: `[ОТ-6]` — основной тест, формула 6. Новые формулы
   получают следующий свободный номер, номер удалённой формулы **не переиспользуется**
   (иначе ссылки в коде начнут указывать не туда).
2. **В коде — одна строка над расчётом**:
   ```cpp
   // [ОТ-8] Сила трения — docs/formulas/main_test.md
   ```
   Искать по номеру: `grep -rn "ОТ-8" Src docs`.
3. **Меняешь формулу в коде — меняешь запись здесь в том же коммите.** Строки с
   пометкой `[XX-n]` — сигнал, что у формулы есть запись.
4. **Контрольный пример** — входные данные и ожидаемый результат. Где пример
   сверен с отчётом приложения — так и написано. Цель (следующий шаг) — проверять
   эти примеры юнит-тестами в `tests/unit/analyzers/`.
5. **Статус**: *официальная* — участвует в результате, Pass|Fail, отчёте;
   *для сравнения* — показывается в карточке способов линейности, в Pass|Fail, отчёт и базу не идёт.
6. **Известные вопросы** — то, что в коде выглядит странно, но **намеренно не
   менялось** без решения: записываем, а не «тихо чиним».

## Обозначения, общие для всех страниц

| значок | что | единицы |
|---|---|---|
| $x$ | давление в приводе | бар |
| $y$ | положение штока | мм (или градусы для поворотных) |
| $i$ | номер замера | — |
| $n$ | число замеров | — |
| $k$, $b$ | наклон и сдвиг прямой $y = kx + b$ | мм/бар, мм |
| мА | задание (ток 4–20 мА; рабочий диапазон 16 мА, 1 % = 0,16 мА) | мА |

  «hysteresis» и «dead band» — п. 5.5.4 и 5.5.2. Отличия от приложения — в main_test.md, раздел ЭЛ.
- IEC 61987 (Electropedia), источник определения — IEC 61298-2, «независимая линейность»:
