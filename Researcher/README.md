# DataResearcher — исследование локальной крутизны

Отдельное приложение на основе карточки DataLabeler. Читает исходные `.data`, использует те же формулы, что DataViewer. Исходные графики и метки DataLabeler не изменяет.

## Запуск

Собрать цель `DataResearcher` в основном проекте. В готовой сборке: `build/Desktop_Debug/Researcher/DataResearcher`.

Нажать **«Открыть архив»** и выбрать общий корень, например `/media/vladislav-b/Tree/Library/рез/`. Приложение в фоне находит сессии тем же `SessionScanner`, что DataLabeler: одна папка с Task, Pressure или Friction — одна сессия. Вложенность папок не требует ручного обхода. Слева появляется плоский список с позицией, датой и контекстом; поиск работает по относительному пути сессии. Неполные сессии также остаются в списке.

Выбрать сессию щелчком или переходить кнопками **«Предыдущая / Следующая»** по результатам поиска. Последний архив и последняя сессия запоминаются и восстанавливаются при запуске без позиционного аргумента. Корень архива или отдельный `.data` также можно передать первым аргументом; при выборе файла открывается его прогон. Поиск сессий не запускает анализ всего архива: расчёт выполняется для открытой карточки.

Один номер прогона используется сразу для Pressure, Task, Friction. Отсутствующий график обозначается пустой карточкой; соседний прогон вместо него не подставляется. Кнопка ⤢ раскрывает отдельный график, повторное нажатие возвращает три. Кнопка **«Копировать сессию»** копирует путь относительно корня архива: позицию и дату можно однозначно передать для обсуждения.

Справа две вкладки:

* **Расчёт**: четыре метода, выбор хода, профиль отклонений и участки. Для локальной крутизны: общий и местный наклон, разница в физических единицах и процентах. Выбранный участок подсвечен на трёх графиках при совместимых единицах и наличии нужной ветви. Итог метода относится к худшему участку/ходу, строка таблицы — к выбранному участку.
* **Наблюдения**: пригодность испытания, выраженность видимой особенности, наблюдатель; отдельные описания Pressure, Task, Friction, предположение/вопрос и подтверждение/замечания к качеству испытания. Автоматической классификации «норма/дефект» по проценту нет.

По умолчанию результаты сохраняются в `Документы/Характеристика локальной крутизны/Результаты_DataResearcher`; `--workspace <папка>` задаёт другое место. На этом компьютере это `/home/vladislav-b/Documents/Характеристика локальной крутизны/Результаты_DataResearcher/`. Кнопка **«Папка результатов»** открывает её из приложения.

Сохранение автоматическое: результат сохраняется после открытия карточки, после паузы при редактировании и перед переключением. В корне **«Сводка.md»** содержит ссылки на все сохранённые карточки. В **«Сессии / позиция и дата / Прогон_N»** находятся **«Результаты.md»** с текущими числами, выбранным участком, таблицей окон и наблюдениями и **«История_правок.md»** с предыдущими сохранениями. Одинаковые названия сессий из разных частей архива различаются по короткому идентификатору. Файлы обновляются автоматически: наблюдения нужно изменять в приложении.

JSON в папке `observations` хранит полную историю правок, исходные пути и SHA-256, выбранные метод, ход, участок и числовые результаты. Читаемые файлы восстанавливаются из этой истории при запуске; удалять её не следует. Ошибка записи не позволяет закрыть окно/переключить карточку с несохранёнными изменениями. Исследовательские записи привязаны к абсолютному пути испытания и номеру прогона; перенос архива требует отдельного переноса соответствий.

**«Сохранить разбор…»** создаёт новую папку: исходные `.data` этого прогона, увеличенные снимки трёх графиков, общий вид, `Разбор.md` с описаниями и `calculation.json` с результатом расчёта. Неполный экспорт помечается `НЕЗАВЕРШЕНО.txt`.

Это версия для совместного разбора и обучения. Числа видны до визуальной оценки; полученные описания нельзя выдавать за независимую слепую экспертную проверку. Границы 5 % / 17 % не заданы в качестве нормативов.

## Проверка

Цель `ResearcherTests`: поиск сессий во вложенном архиве, фильтрация, переходы с сохранением комментариев, восстановление архива и последней сессии; сохранение/история/повреждённая запись, выбранный участок, связи трёх графиков и экспорт без изменения исходных файлов. Существующая цель `PressureAnalysisTests` проверяет расчёт и отображение DataViewer.

На текущем этапе приложение и расчёты проверены в Linux со светлой темой. Сборка для Windows в этой задаче не проверялась. Подборка литературы и предварительный список конференций находятся в `research/local-slope-stability/06_Примеры_статей_и_чтение.md` и `07_Конференции_и_согласование.md`.
