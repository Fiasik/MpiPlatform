В основном тесте программа делит измеренный ход на узкие участки по положению. Для каждого участка со значениями обоих ходов она сравнивает средние значения задания в мА. Крайние участки хода (около 5 % с каждой стороны) пропускаются.

ds = |Īпр,s − Īобр,s|

ds — разница средних заданий на участке s. Средняя динамическая ошибка равна половине среднего значения этих разниц. Максимальная ошибка равна наибольшей разнице целиком.

Eср = d̄ / 2   Eмакс = max(ds)

Для пересчёта в проценты значение в мА делят на 0,16 мА на процент, что соответствует диапазону сигнала 4–20 мА. С допуском Pass | Fail сравнивается средняя ошибка в процентах.

Пример. Средняя разница заданий 0,426 мА даёт ошибку 0,213 мА, или 1,33 %.
