Ток страгивания — значение задания в мА в момент, когда программа обнаружила начало движения. Расчёт выполняется отдельно для прямого и обратного ходов.

За исходное положение y0 берётся медиана первых пяти замеров данного хода. Порог рассчитывается по полному измеренному диапазону положения за оба хода.

δ = 0,002 · (yмакс − yмин)

Медианный фильтр

Для каждой точки после первых пяти замеров берётся медиана положения в окне из пяти значений: двух предыдущих, текущего и двух следующих. Используются только полные окна. Например, для ряда 0; 0; 0,25; 0,25; 0 мм медиана равна 0 мм, поэтому такой выброс не даёт превышения порога.

Программа ищет два последовательных центра окна, в которых |ỹ − y0| > δ, где ỹ — отфильтрованное положение. В результат попадает исходное задание в первом из двух центров. Если подходящей пары нет, значение отсутствует.

Пример. При измеренном ходе 50 мм порог составляет 0,10 мм. Если отфильтрованное положение вышло за порог и первый из двух подряд отсчётов за порогом соответствует заданию 4,8 мА, результат этого хода — 4,8 мА.

Если смещение держится на нескольких соседних замерах, медианный фильтр может его сохранить. При спорном результате сверяйте найденный момент с графиком положения.
